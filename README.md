## Hibernate Learning Project

<h3>📌 Overview :- </h3>

This project is created to learn and understand the fundamentals of Hibernate ORM (Object Relational Mapping) in Java.
It demonstrates how Java objects are mapped to database tables and how CRUD operations are performed using Hibernate.

<h3>🚀 Features</h3>

--> Hibernate configuration setup (XML / Annotations)<br>
--> Entity class mapping<br>
--> Session and Transaction management<br>
--> Basic exception handling
